# Government Adapter — Operational Checklist

*Strategic context: [hetexecs/funding-adapters/govt](https://nsreehari-code.github.io/hetexecs/funding-adapters/index.html)*

---

## Pre-Batch (additional to standard)

- [ ] TP registration active on SID
- [ ] Training Center (TC) geo-tagged and verified on SID
- [ ] Trainer mapped to job role on SID with valid ToT
- [ ] Scheme eligibility confirmed (PMKVY / SSDM / DDU-GKY / NULM)
- [ ] Batch created on SID (any error blocks payment)

## During Batch (additional to standard)

- [ ] Aadhaar biometric attendance captured daily
- [ ] Backup biometric device available
- [ ] Attendance fallback protocol documented (if internet/device fails)
- [ ] SID attendance sync verified weekly
- [ ] Skill India branding visible in all class photos

## Assessment (additional to standard)

- [ ] Third-party assessment agency engaged
- [ ] Assessment scheduled via SSC/NSDC channel
- [ ] Assessor travel and logistics confirmed
- [ ] Assessment result uploaded to portal

## Closure (additional to standard)

- [ ] Batch closed on SID portal
- [ ] Certificate issued via SSC
- [ ] Final attendance reconciliation: portal vs physical register

## Tranche Submissions

### Tranche 1 (Enrollment)
- [ ] Batch enrolled on SID
- [ ] All learner details uploaded and verified
- [ ] Center verified

### Tranche 2 (Assessment)
- [ ] Assessment completed and results uploaded
- [ ] Certificates issued
- [ ] Batch closed on portal

### Tranche 3 (Livelihood)
- [ ] Livelihood evidence compiled (Udyam, income proxy, geo-tagged photos)
- [ ] Evidence uploaded to portal
- [ ] Self-declaration by learners (if required)

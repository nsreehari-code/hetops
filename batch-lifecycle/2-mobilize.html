BL-2: Mobilization & Enrollment

Kill enrollment-time rejections. Think "auditable candidates", not "aware candidates."

Core Question

"Will these candidates pass portal + assessment + livelihood proof?"

Execution Checklist

  • ☐ Learner eligibility verified (Aadhaar, age, bank, phone)
  • ☐ Aadhaar–mobile–bank linkage confirmed
  • ☐ Enterprise pre-existence validated (for women entrepreneurs)
  • ☐ Consent & declaration forms signed
  • ☐ Portal enrollment completed (if govt)

Key Insight

Mobilize pre-qualified learners — women already earning something. Existing SHGs, artisans, home businesses.

Owner

Program Manager + Center Coordinator

BL-3: Batch Kick-Off

Lock Tranche-1 payment. If biometric fails in Week 1, the batch is already wounded.

Core Question

"Can an auditor reconstruct Day 1 exactly?"

Execution Checklist

  • ☐ Day-1 ceremony conducted (branding photos taken)
  • ☐ Biometric dry-run validated (all devices working)
  • ☐ Trainer-learner mapping documented
  • ☐ Batch activation confirmed on SID (if govt)
  • ☐ Baseline captured (income, channels, pricing habits)
  • ☐ WhatsApp group created + code of conduct shared

Owner

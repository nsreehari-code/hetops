# BL-5: Assessment Readiness Checklist

**Owner:** Assessment Lead
**Purpose:** Protect 70% of funding.

## Decision Checklist

- [ ] Mock pass rate ≥ 70%? (If not, escalate)
- [ ] All candidates have complete document files?
- [ ] Assessment agency confirmed dates and logistics?

## Execution Checklist

- [ ] Mock assessment conducted (Week 6 — non-negotiable)
- [ ] Mock results documented per candidate
- [ ] Remedial action plan created for at-risk candidates
- [ ] Extra coaching sessions scheduled (if needed)
- [ ] Assessment agency coordination complete (dates, logistics, assessor travel)
- [ ] Candidate readiness declaration signed
- [ ] All candidate photos, IDs, and artifacts ready for assessor

## Evidence Checklist

- [ ] Mock assessment scores filed
- [ ] Remedial action log filed
- [ ] Assessment agency confirmation email/letter saved
- [ ] Candidate readiness declarations filed

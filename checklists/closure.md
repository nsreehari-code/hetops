# BL-6: Closure Checklist

**Owner:** Documentation Officer + Program Manager
**Purpose:** Close the loop cleanly. Sloppy closure = delayed Tranche-2.

## Execution Checklist

- [ ] Assessment completed (all candidates assessed)
- [ ] Assessment results received from agency
- [ ] Certificates issued to all passing candidates
- [ ] Certificate receipt acknowledgment collected
- [ ] Final attendance reconciliation completed (portal vs actual)
- [ ] Batch closure completed on portal (if govt)
- [ ] Feedback survey collected from all learners
- [ ] Testimonials captured (minimum 3–5, written or video)
- [ ] All physical documents filed and organized
- [ ] Digital evidence archive complete and backed up
- [ ] Sponsor/CSR interim report submitted (if applicable)

## Evidence Checklist

- [ ] Assessment result sheet filed
- [ ] Certificate distribution register filed
- [ ] Final attendance register reconciled and filed
- [ ] Portal closure screenshot saved
- [ ] Feedback survey responses compiled
- [ ] Testimonial files (text/video) archived

# BL-4: Delivery Checklist

**Owner:** Trainer (primary) + Center Coordinator (guardrail)
**Purpose:** Survive audits and avoid attendance disputes.

## Daily Checklist

- [ ] Biometric attendance captured (+ manual fallback if needed)
- [ ] Session conducted as per curriculum plan
- [ ] Learner artifacts produced (per weekly plan)

## Weekly Checklist

- [ ] Attendance rate reviewed (flag if < 80%)
- [ ] Equipment usage verified
- [ ] Internal review note written
- [ ] Documentation Officer: evidence folder up to date

## QA Checkpoint Checklist

### Week 2
- [ ] Attendance trend acceptable
- [ ] First artifact complete for each learner
- [ ] Drop-off risk identified → intervention plan

### Week 4
- [ ] Digital presence verified (WhatsApp catalog live?)
- [ ] Trainer substitution log (if any)
- [ ] Equipment issues escalated

### Week 6
- [ ] Mock assessment conducted
- [ ] Remediation list created
- [ ] Go/no-go decided per candidate

## Trainer Substitution Protocol

- [ ] Backup trainer pre-approved
- [ ] Handover notes prepared
- [ ] Learners informed
- [ ] Attendance continues uninterrupted

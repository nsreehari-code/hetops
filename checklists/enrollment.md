# BL-2: Enrollment Checklist

**Owner:** Program Manager + Center Coordinator
**Purpose:** Kill enrollment-time rejections.

## Decision Checklist

- [ ] Does this candidate meet scheme eligibility criteria?
- [ ] Does this candidate have a pre-existing enterprise? (for entrepreneur courses)
- [ ] Can this candidate realistically pass assessment?

## Execution Checklist

- [ ] Aadhaar copy collected and verified
- [ ] Bank account verified (in candidate's name)
- [ ] Mobile number linked to Aadhaar
- [ ] Aadhaar–mobile–bank linkage confirmed
- [ ] Age eligibility verified
- [ ] Consent & declaration forms signed
- [ ] Enterprise pre-existence validated (photos, product samples)
- [ ] Portal enrollment completed (if govt)

## Evidence Checklist

- [ ] Aadhaar copy filed
- [ ] Bank passbook / cancelled cheque copy filed
- [ ] Consent forms filed
- [ ] Enterprise pre-existence photos archived
- [ ] Portal enrollment screenshot saved

# BL-7: Livelihood Checklist

**Owner:** Documentation Officer
**Purpose:** Turn training into money. If documentation lags, Tranche-3 dies.

## Day 30 Checklist

- [ ] Follow-up call completed for each learner
- [ ] WhatsApp catalog still active? (screenshot)
- [ ] At least 1 sales transaction or inquiry? (evidence captured)
- [ ] Any learner needing support identified → intervention

## Day 60 Checklist

- [ ] Follow-up call completed
- [ ] Income proxy collected (orders/month, UPI transactions, repeat customers)
- [ ] Udyam certificate obtained (or registration in progress)
- [ ] Geo-tagged photos taken (if applicable)

## Day 90 Checklist

- [ ] Final follow-up completed
- [ ] Success story / testimonial captured (compelling, specific)
- [ ] Peer mentoring connection made (connecting strong learners to new cohort)
- [ ] Referral captured (for next batch)
- [ ] Income evidence compiled into proof pack
- [ ] Tranche-3 submission prepared (if govt)
- [ ] Impact report submitted (if CSR)
- [ ] CCF Section I (Iteration Notes) filled

## Evidence Pack (Final)

- [ ] Udyam certificates
- [ ] Digital storefront screenshots
- [ ] Income proxy documents (UPI, bank, order threads)
- [ ] Geo-tagged photos
- [ ] Testimonials / success stories
- [ ] Before/after income comparison

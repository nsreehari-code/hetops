BL-1: Pre-Authorization

Owner: Program Manager

Core question: "If I open this batch today, can I survive till Tranche-3?"

Verify scheme eligibility, center readiness (branding, biometric, internet), trainer validity (ToT active), district approval, and cash flow projection. If Pre-Auth fails → do not open the batch.

BL-2: Mobilization & Enrollment

Owner: Program Manager + Center Coordinator

Core question: "Will these candidates pass portal + assessment + livelihood proof?"

Verify Aadhaar, bank, mobile linkage. Validate enterprise pre-existence (for entrepreneur courses). Complete portal enrollment. Mobilize pre-qualified learners — women already earning something.

BL-3: Batch Kick-Off

Owner: Program Manager + Center Coordinator

Core question: "Can an auditor reconstruct Day 1 exactly?"

Day-1 ceremony, branding photos, biometric dry-run, trainer-learner mapping, SID batch activation (if govt), baseline capture (income, channels, habits), WhatsApp group.

BL-4: Training Delivery

Owner: Trainer (primary) · Center Coordinator (guardrail)

Core question: "Can I defend every class conducted?"

Daily biometric attendance, weekly review, QA checkpoints at Week 2/4/6. Delivery is compliance-critical — an un-defended class = audit risk.

BL-5: Assessment Readiness

Owner: Assessment Lead

Core question: "Who is likely to fail, and why?"

Mock assessment at Week 6 (non-negotiable). Remedial action for at-risk candidates. Assessment agency coordination. Every failed candidate = lost revenue.

BL-6: Certification & Closure

Owner: Documentation Officer + Program Manager

Core question: "Is anything left unuploaded or unverified?"

Certificates issued, attendance reconciled, batch closed on portal, documents archived, feedback + testimonials collected. Sloppy closure = delayed Tranche-2.

BL-7: Livelihood & Tranche-3

Owner: Documentation Officer

Core question: "Can I prove income?"

30/60/90-day follow-up. Evidence: Udyam certificate, digital storefront screenshots, UPI transactions, geo-tagged photos, success stories. This stage determines profitability.

Stage 5: Launch

Batch setup, onboarding, baseline capture. This is where Tranche-1 gets locked.

Core Question

"Can an auditor reconstruct Day 1 exactly?"

Day 1 Execution

  • Enrollment verification (all documents complete)
  • Baseline capture (current income range, current channels, pricing habits)
  • Attendance system test (biometric if govt)
  • WhatsApp group + code of conduct
  • Tools check (phone + UPI + photos)

What You Create

  • CCF Section F (Operations Plan — filled now)
  • CCF Section G (Launch Go/No-Go Checklist)

Funding Adapter Differences

ModelWhat changes
GovtBiometric + portal enrollment are make-or-break. If biometric fails in Week 1, the batch is already wounded.
CSRConsent + safeguarding + sponsor reporting fields

Go / No-Go Checklist

  • ☐ Center readiness (branding, internet, biometric devices)
  • ☐ Trainer readiness (ToT valid, materials ready)
  • ☐ Learner readiness (all docs verified, Aadhaar-mobile-bank linked)
  • ☐ Tool readiness (phones, UPI, printer/scanner)
  • ☐ Funding readiness (contracts/MOUs signed, portal batch created)

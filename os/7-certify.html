Stage 7: Certify / Close

Assessment, certificates, archive, batch closure. Sloppy closure = delayed Tranche-2.

Core Question

"Is anything left unuploaded or unverified?"

Closure Actions

  • Practical assessment + capstone presentation
  • Certificates issued
  • Evidence pack archived (screenshots, workbook, photos)
  • Feedback survey + testimonial capture
  • Batch closed on portal (if govt)

What You Create

  • CCF Section H (Closure Checklist — filled now)

Closure Checklist

  • ☐ Assessment completed (all candidates assessed)
  • ☐ Certificates issued (to all passing candidates)
  • ☐ Final attendance reconciliation done
  • ☐ Evidence pack archived (complete)
  • ☐ Batch closure on portal (govt) / report submitted (CSR)
  • ☐ Feedback collected
  • ☐ Testimonials captured (3–5 minimum)
  • ☐ Outcome follow-up plan activated (30/60/90)

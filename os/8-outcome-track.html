Stage 8: Outcome Track

30/60/90 follow-up, livelihood evidence, iteration learning. This is where profitability is determined and strategic learning feeds back to hetexecs.

Core Question

"Can I prove income?"

Outcome Tracking Plan

DayWhat to verify
Day 30Catalog still active, at least 1 sales transaction (or inquiry volume)
Day 60Income proxy — orders/month, repeat customers
Day 90Success story capture, peer mentoring, referral generation

What You Create

  • CCF Section I (Iteration Notes — what worked, what failed, what changes next run)

Actors

ActorRole
Documentation Officer30/60/90 follow-up calls, evidence collection
Program ManagerOutcome reporting, iteration notes
CEOStrategic learning — "did this course family work?"
Learners (alumni)Provide proof (Udyam, catalog screenshots, income evidence)
Govt: SID / scheme authorityTranche-3 verification
CSR: SponsorImpact report review

Evidence Artifacts

  • ☐ Udyam certificate (screenshot or registration number)
  • ☐ Digital storefront evidence (WhatsApp catalog live screenshot)
  • ☐ Income proxy (UPI transactions, order threads, bank statement extract)
  • ☐ Geo-tagged photos (market stall, product display)
  • ☐ Testimonial / success story (written or video)

Funding Adapter Differences

ModelWhat changes
GovtLivelihood proof determines final tranche. Over-document, don't under-document.
CSRImpact report + success stories for sponsor
PaidReferrals + repeat purchases are the growth engine

Feedback Loop to Strategy

Stage 8 feeds directly back to hetexecs:

  • Pinboard → Experiments lane (what format worked)
  • Pinboard → Evidence lane (what proof convinced)
  • Pinboard → Ops Learnings lane (what broke)
  • Portfolio → health signals updated
  • Versions → new version triggered if shape needs to change

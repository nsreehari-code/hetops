# Batch Runbook — Week-by-Week Operational Playbook

*Template for an 8-week batch. Adjust for course-specific rhythm.*

---

## Pre-Batch (Week -2 to -1)

- [ ] Funding confirmed / MOU signed
- [ ] Center readiness verified
- [ ] Trainer assigned + materials ready
- [ ] Enrollment target set + mobilization active
- [ ] Batch created on portal (if govt)
- [ ] CCF Sections D–G filled

---

## Week 1: Launch
- [ ] Day-1 ceremony + branding photos
- [ ] Biometric system tested
- [ ] Baseline captured (income, channels, habits)
- [ ] All learner documents verified
- [ ] WhatsApp group active

## Week 2: QA Checkpoint 1
- [ ] Attendance rate reviewed
- [ ] First artifact produced by each learner
- [ ] Any drop-off risk? → intervention
- [ ] Documentation Officer: evidence folder current

## Week 3–4: Core Delivery
- [ ] Attendance tracking stable
- [ ] Artifacts accumulating per learner
- **Week 4 QA Checkpoint 2:**
  - [ ] Digital presence verified (catalog live?)
  - [ ] Trainer substitution needed?
  - [ ] Equipment issues?

## Week 5: Ramp to Assessment
- [ ] Content creation artifacts complete
- [ ] Assessment agency coordinated (dates set)
- [ ] Remedial list started (who needs extra coaching?)

## Week 6: Mock Assessment (Non-Negotiable)
- [ ] Mock conducted
- [ ] Remedial action plan for at-risk candidates
- [ ] Go/no-go decision for each candidate
- **Week 6 QA Checkpoint 3:**
  - [ ] Mock pass rate reviewed
  - [ ] Evidence completeness checked
  - [ ] Escalate if pass rate < 70%

## Week 7: Formalization
- [ ] Udyam awareness / registration support
- [ ] Loan readiness awareness
- [ ] Final coaching for weak candidates

## Week 8: Capstone & Closure
- [ ] Capstone presentation / assessment
- [ ] Certificates issued
- [ ] Feedback collected
- [ ] Testimonials captured (3–5 minimum)
- [ ] Batch closed on portal
- [ ] Evidence archive complete
- [ ] 30/60/90 follow-up calendar set

---

## Post-Batch (Day 30 / 60 / 90)
- [ ] Day 30: Catalog active? Transaction proof?
- [ ] Day 60: Income proxy collected
- [ ] Day 90: Success story captured, referral generated
- [ ] CCF Section I filled (iteration notes)
- [ ] Tranche-3 submission (if govt)

---

*This is a template. Create one instance per batch.*
